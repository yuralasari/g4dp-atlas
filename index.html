About

This is a starting point for a website that tells a story with maps. It is plain HTML and CSS, with maplibre-yaml, which turns a YAML file into a MapLibre map. There is nothing to install and no build step: every map on this site is a file in maps/ or stories/, so you edit the YAML, not code.

  • Inline maps (inline-maps.html): maps placed in a page between text and images, with popups, a legend, layer toggles, and a map beside text in two columns.
  • Full page map (full-page-map.html): one map that fills the window, with zoom buttons, a legend and a layer panel.
  • Scrollytelling (scrollytelling.html and stories/nyc.yaml): a story map whose chapters move the camera and show and hide layers as you scroll.

To find the center and zoom for a map, move around this location helper and copy the numbers.
